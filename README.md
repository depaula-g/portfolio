## 📂 Projetos apresentados

### 1. Portfólio Pessoal
Site desenvolvido com HTML, CSS, Bootstrap e JavaScript para apresentar informações profissionais, tecnologias e projetos acadêmicos.

### 2. Sistema de Controle de Estoque
Aplicação desenvolvida em Python para controlar o estoque de uma lanchonete, utilizando listas, entrada de dados e estruturas condicionais para identificar produtos com estoque baixo.

🔗 [Visualizar repositório](https://github.com/depaula-g/estoque-lanchonete)

### 3. Página Frutiger Aero
Página web desenvolvida com HTML, CSS e Bootstrap, inspirada na estética Frutiger Aero, utilizando efeitos de transparência, cores vibrantes e elementos visuais personalizados.
